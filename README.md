# 助学金评定管理系统
## 项目介绍
课程实训后台管理项目，主要实现学生助学金线上申请、管理员审核、信息管理等基础业务功能，完成后端接口开发、数据库设计与简易前端页面搭建，同时完成接口自测与数据联调。

## 技术栈
后端：SpringBoot、MyBatis
数据库：MySQL
前端：HTML、CSS

## 主要功能
1. 学生信息录入与查询
2. 助学金在线申请提交
3. 申请状态审核管理
4. 基础数据维护

## 项目特点
1. 结构清晰，分层规范，适合初学练手
2. 自带美化前端页面，可直接本地运行访问
3. 完成接口自测，熟悉后端业务与基础测试流程

## 运行方式
1. 创建MySQL数据库并导入对应数据表
2. 修改配置文件内数据库账号密码
3. 启动项目，浏览器访问本地端口即可使用
